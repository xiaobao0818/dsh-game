# 星海幸存者 · 设计说明

## 主题

- 题材：太空科幻（space）
- 主色：#5ce1ff / #ff7ad9
- 货币：金币

## 核心循环

拖动走位、武器自动开火，在尸潮里活到倒计时归零。击杀掉经验宝石，升级时暂停三选一强化；每关最后刷出 Boss，活过倒计时即胜利（提前击杀 Boss 也能立刻结束）。
