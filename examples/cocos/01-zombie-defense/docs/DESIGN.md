# 僵尸围山门 · 设计说明（Cocos 版）

## 主题

- 题材：中式僵尸（night）
- 主色：#ffcf5c / #ff7a59
- 货币：铜钱

## 核心循环

造屋自动派兵，挡住从右侧涌来的游尸潮，守住山门。漏怪会啃山门，耐久归零就失败。

## 内容规模

- 关卡：30
- 章节：荒村 / 山门 / 乱葬岗 / 鬼市 / 尸王殿
- 定义表：buildings(4)、units(4)、enemies(4)、spells(3)
