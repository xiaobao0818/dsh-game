# 三十天开播 · 设计说明（Cocos 版）

## 主题

- 题材：都市夜景（dusk）
- 主色：#ffd76a / #ff5d8f
- 货币：营业额

## 核心循环

30 天为一轮：每天花行动点招人或升级，点「开始营业」结算当日收益。第 30 天结束时，营业额与粉丝都达到目标即通关；中途发不出工资或租金就算破产失败。

## 内容规模

- 关卡：24
- 章节：老小区篇 / 步行街篇 / 写字楼篇 / 地铁口篇 / 天台篇 / 夜市篇
- 定义表：roles(4)、venues(5)、shows(3)、events(6)
