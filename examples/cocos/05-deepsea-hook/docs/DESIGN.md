# 深海打捞 · 设计说明（Cocos 版）

## 主题

- 题材：海底打捞（underwater）
- 主色：#5ce1e6 / #ffd166
- 货币：金币

## 核心循环

站在海底木筏上摆动钩爪，把水里的宝物抓回来。每关限时，得分达到目标分即过关；提前达标可点底部收工按钮结算，剩下的时间继续捞可以拿更高星级。

## 内容规模

- 关卡：24
- 章节：浅滩 / 珊瑚海 / 沉船区 / 深海沟 / 漩涡 / 幽灵湾
- 定义表：items(8)、hazards(6)、upgrades(4)、economy(undefined)、tiers(4)
