# 三十天开播

> 按天经营，选节目/员工/升级，滚大收益，在期限内达成目标。

**都市夜景 · 保安的生意** · 都市夜景 · 24 关 · 竖屏

## 一句话

主播模拟经营的放置游戏，24关，竖屏

## 直接玩

- 单文件离线版：`dist/三十天开播.html`（双击打开，零外部请求）
- 工程版：`node tools/serve.mjs 8080` → http://127.0.0.1:8080

## 操作

- 点员工卡「招募」：花行动点 + 铜钱雇人，自动产出
- 点下方员工头像：花行动点 + 铜钱升级（最高 Lv.5）
- 点「升级场地」：加容量、加单价，但每日租金变高
- 点节目按钮：当天收入/粉丝加成（每天限一次）
- 点「开始营业」进入当日结算，结算面板里点「下一天」继续

## 目标

30 天为一轮：每天花行动点招人或升级，点「开始营业」结算当日收益。第 30 天结束时，营业额与粉丝都达到目标即通关；中途发不出工资或租金就算破产失败。

## 工程结构

```

css/style.css         基础样式
js/core.js            纯逻辑：数学/随机/存档（可在 Node 跑）
js/platform.js        布局/WebAudio/粒子/输入
js/render.js          绘制工具
js/art.js             程序化美术（主题调色板）
js/app.js             外壳：场景/主循环/存档/暂停
js/content.js         全部内容数据（可手改）
js/rules/idle.js 玩法规则（可手改）
tools/                预览/构建/无头仿真/浏览器冒烟/自检
docs/                 设计说明与测试报告
```
