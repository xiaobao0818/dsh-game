# 深海打捞

> 摆钩抓宝，越重越慢；限时达标，升级钩爪。

**海底打捞 · 深海机师的冒险** · 海底打捞 · 24 关 · 竖屏

## 一句话

海底钩爪打捞寻宝，24关，竖屏

## 直接玩

- 单文件离线版：`dist/深海打捞.html`（双击打开，零外部请求）
- 工程版：`node tools/serve.mjs 8080` → http://127.0.0.1:8080

## 操作

- 点击屏幕 / 空格：沿当前摆动方向发射钩爪
- 抓到宝物加分；越重的宝物回收越慢
- 危险物（废旧/爆裂/危险生物）会扣分，抓到爆弹还会短暂僵直
- 关卡开始前可以用金币升级：力度 / 绞盘 / 瞄准 / 幸运

## 目标

站在海底木筏上摆动钩爪，把水里的宝物抓回来。每关限时，得分达到目标分即过关；提前达标可点底部收工按钮结算，剩下的时间继续捞可以拿更高星级。
