# 老小区归位 · 测试与验收

## 自动检查

```bash
node tools/check.mjs
```

覆盖：

1. **数据校验**：关卡 id 连续、章节覆盖、数值有限。
2. **无头仿真**：机器人脚本在固定步长下逐关试玩，要求 25/25 通关；不操作（摆烂）应大量失败。
3. **单文件构建**：内联全部 JS/CSS，校验零外部引用与体积。
4. **浏览器冒烟**：无头 Chrome 打开工程版，收集异常/console.error，检查 FPS≥45；截图写入 `shots/`。
